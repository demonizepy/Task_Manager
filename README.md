# 📝 Менеджер задач

Небольшое приложение на C# для ведения списка задач. Интерфейс на WPF из нескольких окон, светлая и тёмная тема, русский и английский язык.

## 🚀 Возможности

* Добавление задач в отдельном окне (ID и описание)
* Удаление выбранных в списке задач (кнопкой или клавишей Delete) или по ID через запятую
* Полная очистка списка с подтверждением
* Автоматическое сохранение в файл и загрузка при запуске
* Подсказка следующего свободного ID
* Светлая и тёмная тема, переключаются без перезапуска
* Русский и английский язык интерфейса, тоже без перезапуска
* Выбранные тема и язык запоминаются

# ▶️ Запуск проекта

Через код:

1. Открыть `Task_Manager.sln` в Visual Studio 2022 (17.8 и новее)
2. Если студия предложит доустановить компоненты, поставить «Разработка классических приложений .NET»
3. Убедиться, что запускаемый проект — `Task_Manager` (правый клик → «Назначить автозагружаемым проектом»)
4. Нажать `F5`

Демонстрация модуля без окон: правый клик по `Task_Manager.Demo` → «Отладка» → «Запустить новый экземпляр».

Через релизы (без установки Visual Studio):

1. Перейдите на страницу Releases в этом репозитории.
2. В самом верхнем (последнем) релизе разверните список Assets.
3. Скачайте прикрепленный архив с программой или файл Task_Manager.exe.
4. Если вы скачали архив — распакуйте его в любую удобную папку.
5. Запустите файл Task_Manager.exe (установка не требуется).

# 💾 Хранение данных

Задачи лежат в файле `tasks.txt` рядом с exe (`Task_Manager\bin\Debug\net8.0-windows`), по одной на строку:

```text
1|Сделать лабораторную
2|Купить хлеб
```

Тема и язык сохраняются в `settings.json` в той же папке:

```json
{
  "Theme": "Dark",
  "Language": "English"
}
```

# 🕓 История версий

1. Интерфейс на русском, убраны вылеты при неверном вводе
2. Появились классы `TaskItem` и `TaskManager`
3. Код разложен по папкам: `Models`, `Services`, `UI`
4. Переход на Windows Forms, консольное меню заменено окном
5. Удаление по ID, Enter для добавления, обработка ошибок файла
6. Переход на WPF: отдельные окна для добавления, удаления по ID и «О программе»; логика вынесена в библиотеку `Task_Manager.Core`, добавлен демо-проект
7. Светлая и тёмная тема, русский и английский язык, окно настроек; сообщения показываются своим окном в цвет темы
