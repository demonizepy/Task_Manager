# Консольный менеджер задач

Простое консольное приложение на C# для ведения списка задач. Данные сохраняются в текстовый файл, поэтому список не теряется между запусками.

## Возможности

- **Добавление задачи** с числовым ID и описанием. Если ID уже занят, описание заменяется новым.
- **Удаление задачи** по ID. Можно удалить сразу несколько, указав ID через запятую (например, `1, 3, 5`).
- **Просмотр** всех задач.
- **Очистка списка** с подтверждением.
- **Автосохранение** в файл `tasks.txt` после каждого действия в меню.
- Проверка ввода: пустое описание и нечисловой ID не принимаются.
- Поддержка кириллицы в консоли (UTF-8).

## Требования

- [.NET SDK](https://dotnet.microsoft.com/download) 5.0 или новее

## Запуск

```bash
git clone https://github.com/demonizepy/Task_Manager.git
cd Task_Manager
dotnet run
```

## Использование

После запуска появится меню:

```
1. Добавить задачу
2. Удалить задачу
3. Показать задачи
4. Очистить список
5. Выход
```

Введите номер пункта и следуйте подсказкам. При выходе приложение спрашивает, продолжить работу или завершить её.

## Формат хранения данных

Задачи лежат в `tasks.txt` рядом с исполняемым файлом, по одной на строку:

```
<ID>|<описание>
```

Пример:

```
1|Купить молоко
2|Сделать домашнее задание
```

Файл можно редактировать вручную: некорректные строки при загрузке пропускаются.

## Структура проекта

| Метод | Назначение |
|---|---|
| `ShowMenu` | главное меню и выбор действия |
| `AddTask` / `DeleteTask` / `DisplayTasks` / `ClearAllTasks` | операции над списком |
| `SaveTasks` / `LoadTasks` | запись и чтение `tasks.txt` |
| `ReadInt` | безопасное чтение числа из консоли |
