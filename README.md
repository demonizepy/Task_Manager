# Task_Manager

Консольный менеджер задач на C#. Задачи сохраняются в текстовый файл, поэтому список не теряется между запусками.

Это версия **v3**: проект переработан с разделением ответственности на отдельные слои — модели, сервисы и консольный интерфейс.

## Возможности

- **Добавление задачи** с числовым ID и описанием.
- Если ID уже существует, его описание заменяется.
- **Удаление одной или нескольких задач** по ID через запятую.
- Отдельная обработка:
  - удалённых задач;
  - не найденных ID;
  - некорректных значений.
- **Просмотр** всех задач, отсортированных по ID.
- **Очистка списка** с подтверждением.
- **Автосохранение** задач после каждого действия меню.
- Проверка числового ввода.
- Проверка пустого описания задачи.
- Поддержка кириллицы в консоли через UTF-8.
- Загрузка задач из `tasks.txt` при запуске.

## Архитектура

В версии v3 логика проекта разделена на несколько частей:

- **Models** — модели данных.
- **Services** — работа с задачами и хранением данных.
- **UI** — консольное меню и ввод пользователя.

Такой подход позволяет не смешивать бизнес-логику с отображением меню и обработкой пользовательского ввода.

## Требования

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Windows, Linux или macOS с установленным .NET 8

## Запуск

```bash
git clone https://github.com/demonizepy/Task_Manager.git
cd Task_Manager/Task_Manager
dotnet run
```

## Использование

После запуска отображается меню:

```text
1. Добавить задачу
2. Удалить задачу
3. Показать задачи
4. Очистить список
5. Выход
```

Выберите нужный пункт и следуйте инструкциям в консоли.

При добавлении задачи необходимо указать ID и описание.

Для удаления можно указать несколько ID:

```text
1, 3, 5
```

Программа отдельно сообщает, какие задачи удалены, какие ID не найдены и какие значения введены некорректно.

## Формат хранения данных

Задачи сохраняются в файле `tasks.txt` в папке приложения.

Каждая задача записывается отдельной строкой:

```text
<ID>|<описание>
```

Пример:

```text
1|Купить молоко
2|Сделать домашнее задание
5|Подготовиться к контрольной
```

При загрузке некорректные строки пропускаются.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Program.cs` | точка входа и запуск консольного меню |
| `Models/TaskItem.cs` | класс `TaskItem`: одна задача (ID и описание) |
| `Models/RemoveResult.cs` | класс `RemoveResult`: результат удаления задач |
| `Services/TaskManager.cs` | класс `TaskManager`: хранение списка задач, добавление, удаление и очистка |
| `Services/TaskStorage.cs` | класс `TaskStorage`: загрузка и сохранение задач в `tasks.txt` |
| `UI/ConsoleInput.cs` | класс `ConsoleInput`: проверка и обработка пользовательского ввода |
| `UI/ConsoleMenu.cs` | класс `ConsoleMenu`: консольное меню и взаимодействие с пользователем |
