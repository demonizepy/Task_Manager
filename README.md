# Task_Manager

Консольный менеджер задач на C#. Задачи хранятся в текстовом файле, поэтому список не теряется между запусками.

Это версия **v2**: логика работы со списком вынесена из `Program.cs` в отдельные классы.

## Возможности

- **Добавление задачи** с числовым ID и описанием. Если ID уже занят, описание заменяется, и программа сообщает об этом.
- **Удаление задачи** по ID. Можно удалить сразу несколько, указав ID через запятую (например, `1, 3, 5`).
- **Просмотр** всех задач, отсортированных по ID.
- **Очистка списка** с подтверждением.
- **Автосохранение** в файл `tasks.txt` после каждого действия в меню.
- Проверка ввода: пустое описание и нечисловой ID не принимаются.
- Поддержка кириллицы в консоли (UTF-8).

## Требования

- [.NET SDK](https://dotnet.microsoft.com/download) 6.0 или новее

## Запуск

```bash
git clone https://github.com/demonizepy/Task_Manager.git
cd Task_Manager/Task_Manager
dotnet run
```

## Использование

После запуска появится меню:

```
1. Добавить задачу
2. Удалить задачу
3. Показать задачи
4. Очистить список
5. Выход
```

Введите номер пункта и следуйте подсказкам. При выборе «Выход» программа уточняет, продолжить работу или завершить её.

## Формат хранения данных

Задачи сохраняются в `tasks.txt` в папке, из которой запущено приложение, по одной задаче на строку:

```
<ID>|<описание>
```

Пример:

```
1|Купить молоко
2|Сделать домашнее задание
```

Файл можно редактировать вручную: некорректные строки при загрузке пропускаются.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Program.cs` | точка входа, меню и взаимодействие с пользователем (ввод и вывод) |
| `TaskManager.cs` | класс `TaskManager`: хранение списка задач, добавление, удаление, очистка, сохранение в файл и загрузка из него |
| `TaskItem.cs` | класс `TaskItem`: одна задача (ID и описание) |
