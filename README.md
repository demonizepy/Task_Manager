# Task_Manager

Менеджер задач на C# с графическим интерфейсом Windows Forms. Задачи сохраняются в текстовый файл и автоматически восстанавливаются после перезапуска программы.

Это версия **v5** — доработанная версия графического приложения с улучшенной обработкой ввода, удалением задач по ID и дополнительными проверками.

## Возможности

- **Добавление задачи** с числовым ID и описанием.
- Автоматическая установка следующего свободного ID.
- Если выбранный ID уже занят, программа предлагает заменить описание существующей задачи.
- **Удаление выбранных задач** из списка.
- **Удаление задач по ID** — можно указать несколько ID через запятую:
  ```text
  1, 3, 5
  ```
- Отдельный вывод результатов удаления:
  - удалённые задачи;
  - не найденные ID;
  - некорректные значения.
- **Очистка всего списка** с подтверждением.
- **Автосохранение** после каждого изменения данных.
- Загрузка задач из `tasks.txt` при запуске.
- Отображение количества задач.
- Поддержка клавиши `Delete` для удаления выбранных задач.
- Кнопка действия меняется для поля удаления: `Enter` в этом поле запускает удаление по ID.
- Проверка пустого описания.
- Обработка ошибок чтения и записи файла.

## Интерфейс

Главное окно состоит из нескольких областей.

### Добавление задачи

В верхней части находятся:

- поле **ID**;
- поле **Описание**;
- кнопка **Добавить**.

Поле ID автоматически устанавливается на следующий ID после добавления или удаления задач.

Если указанный ID уже существует, программа показывает подтверждение:

```text
Задача с ID ... уже есть. Заменить её описание?
```

### Список задач

Задачи отображаются в таблице с двумя столбцами:

```text
ID | Описание
```

Можно выбрать одну или несколько задач и удалить их кнопкой **Удалить выбранные** или клавишей `Delete`.

### Удаление по ID

В нижней части окна можно ввести несколько ID через запятую:

```text
1, 2, 5
```

Программа определяет результат для каждого значения отдельно.

Например:

```text
Удалено: 1, 2
Не найдено: 5
Неверный ID: abc
```

### Очистка списка

Кнопка **Очистить всё** удаляет все задачи только после подтверждения пользователя.

## Требования

- Windows
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Visual Studio 2022 или другая среда разработки с поддержкой .NET 8 и Windows Forms

## Запуск

```bash
git clone https://github.com/demonizepy/Task_Manager.git
cd Task_Manager/Task_Manager
dotnet run
```

Или откройте:

```text
Task_Manager.sln
```

в Visual Studio.

## Формат хранения данных

Задачи хранятся в файле `tasks.txt` в папке приложения.

Формат:

```text
<ID>|<описание>
```

Пример:

```text
1|Купить молоко
2|Сделать домашнее задание
3|Подготовить проект
```

При загрузке программа проверяет строки файла. Некорректные записи пропускаются.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Program.cs` | точка входа и запуск главной формы |
| `Forms/MainForm.cs` | класс `MainForm`: графический интерфейс, добавление, удаление задач и обработка действий пользователя |
| `Forms/MainForm.Designer.cs` | создание и настройка элементов Windows Forms |
| `Models/TaskItem.cs` | класс `TaskItem`: одна задача (ID и описание) |
| `Models/RemoveResult.cs` | класс `RemoveResult`: хранение результатов удаления — удалённые, не найденные и некорректные ID |
| `Services/TaskManager.cs` | класс `TaskManager`: управление списком задач, добавление, удаление, очистка и поиск следующего свободного ID |
| `Services/TaskStorage.cs` | класс `TaskStorage`: загрузка и сохранение задач в `tasks.txt`, обработка ошибок файловой системы |
